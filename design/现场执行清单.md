# 现场执行清单（运动 + 视频采集）

本清单目标：下午到机器人旁边时“照着做”，采集结束后带走 `runs/<run_id>/` 目录即可离线复盘。

## 0. 你需要准备什么

PC（Windows）：
- Python（能运行 `python`）
- Node.js（能运行 `node`，用于后端）
- ffmpeg（能运行 `ffmpeg`，用于录视频）

机器人（Linux）：
- 能运行从机：`bash scripts/start_slave.sh`（含 ROS2/AimDK 环境）
- 机器人热点网段一般是 `192.168.88.88`（以实际为准）

## 1. PC 端启动后端（必须）

在 PC 仓库根目录运行：
```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_backend.ps1 -Port 8765 -AsrMode master
```

可选（建议）：锁定机器人热点主机（用于 `/proxy/robot/*` 代理白名单）：
```powershell
set ROBOT_HOST=192.168.88.88
```

健康检查（浏览器打开即可）：
- `http://127.0.0.1:8765/health`

## 2. 机器人端启动从机 + MJPEG（用于采视频）

在机器人上（`bot_connect` 根目录）设置：
```bash
export WS_URL="ws://<PC_IP>:8765"
export STREAM_MODE="http_mjpeg"
export STREAM_AUTOSTART="1"
export STREAM_HTTP_BASE="8000"
export STREAM_PUBLIC_HOST="192.168.88.88"
```

然后启动：
```bash
bash scripts/start_slave.sh
```

说明：
- `STREAM_HTTP_BASE=8000` 会按 topics 顺序占用端口：`8000/8001/8002/8003...`
- `STREAM_PUBLIC_HOST` 不要依赖自动猜测，热点/多网卡很容易猜错。

## 3. PC 端一键采集（WS + 多路视频）

在 PC 上新开一个 PowerShell 窗口运行：
```powershell
powershell -ExecutionPolicy Bypass -File scripts\capture_run.ps1 `
  -WsUrl ws://127.0.0.1:8765 `
  -DurationSec 1800 `
  -RunId 20260424_1500 `
  -Types "status,result,vision" `
  -Streams @(
    "rear=http://127.0.0.1:8765/proxy/robot/mjpg?port=8000&path=/stream.mjpg",
    "left=http://127.0.0.1:8765/proxy/robot/mjpg?port=8001&path=/stream.mjpg",
    "right=http://127.0.0.1:8765/proxy/robot/mjpg?port=8002&path=/stream.mjpg"
  )
```

采集结果：
- `runs/20260424_1500/ws.jsonl`
- `runs/20260424_1500/video/*.mp4`
- `runs/20260424_1500/summary.md`（采集结束自动生成）

## 4. 现场运动采样（边录边跑）

用现成发送脚本（PC 上执行）：
```powershell
set WS_URL=ws://127.0.0.1:8765
set TARGET=slave-01
set ACTION=motion.move
set LIN=0.1
set ANG=0
set LAT=0
set DUR=1
python backend\send_exec.py
```

停止：
```powershell
set ACTION=motion.stop
python backend\send_exec.py
```

建议采样动作序列（便于对齐视频）：
1) 前进 1s（LIN=0.1）  
2) 停止 1s  
3) 左转 1s（ANG=0.4）  
4) 停止 1s  
5) 侧移 1s（LAT=0.1）  
6) 停止 1s  

## 5. 采集结束后你带走什么

只需要拷走整个目录：
- `runs/<run_id>/`

离线复盘入口：
- 先看 `runs/<run_id>/summary.md`
- 需要更细再打开 `runs/<run_id>/ws.jsonl` 与 `runs/<run_id>/video/*.mp4`

## 6. 现场常见问题快速定位

### 6.1 运动“看起来 ok 但机器人不动”

优先看 `runs/<run_id>/summary.md` 里这两项：
- `motion.sim_mode` 如果是 `true`：说明 ROS/AimDK 初始化失败，属于“假成功”（WS 层 ok，但未真实发布）。
- `motion.ros.ready` 如果是 `false`：同上。

同时可在机器人上辅助确认（有 ROS 的情况下）：
- `ros2 topic echo /cmd_vel`
- 或检查是否存在 `/aima/mc/locomotion/velocity`

### 6.2 录不到视频 / mp4 为空

先看：
- `runs/<run_id>/video/*_ffmpeg.log`（是否 timeout/404/connection reset）

再看机器人侧 MJPEG 子进程日志（从机已落盘）：
- `runs/stream_logs/mjpeg_<port>_<topic>.log`

### 6.3 前端能看但 PC 录制拉不到

尽量统一都走同源代理录制：
- `http://127.0.0.1:8765/proxy/robot/mjpg?port=800X&path=/stream.mjpg`

不要直接录 `http://192.168.88.88:800X/stream.mjpg`（跨网段设备经常不可达）。
