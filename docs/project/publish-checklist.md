# 发布与截图清单

## 上传前检查

- 确认 `backend/config.json` 没有硬编码个人凭据。
- 确认 `docs/` 中没有局域网专用地址。
- 确认 `vision_yolo/models/`、`runs/`、录制文件没有被提交。
- 确认 `node_modules/`、`dist/`、`build/`、`install/`、`log/` 已被忽略。

## 启动顺序

1. 启动后端。
2. 启动前端。
3. 启动主机模拟或机器人端服务。
4. 打开前端页面并确认连接状态。
5. 打开监控页或控制页准备截图。

## 建议截图

- 控制台首页
- 设置页
- 监控页
- 动作控制页
- 后端终端日志
