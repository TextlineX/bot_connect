# 总览与架构

Bot Connect 是一个用于机器人控制、交互和监控的项目，采用前端控制台 + 后端中转 + 机器人主从客户端的结构。

## 系统架构

```text
┌──────────────────────────────┐
│          前端控制台          │
│   http://<PC_IP>:5173        │
└──────────────┬───────────────┘
               │ WebSocket
               ▼
┌──────────────────────────────┐
│         后端中转服务         │
│      ws://<PC_IP>:8765       │
└───────┬──────────┬───────────┘
        │          │
        ▼          ▼
   Master 客户端   Slave 客户端
   ASR / AI / TTS   运动 / 视频流 / TTS
```

## 核心模块

| 模块 | 作用 |
|------|------|
| `backend` | 负责消息路由、配置同步、音频处理和中转 |
| `frontend` | 提供控制、监控、设置和调试界面 |
| `master` | 处理语音识别、AI 解析和动作路由 |
| `slave` | 处理运动、视频流和执行结果回传 |
| `vision_yolo` | 视觉推理和目标跟踪 |
| `common` | 共享工具库 |
| `scripts` | 启动、测试和辅助工具 |

## 数据流

1. 前端发起控制和配置同步。
2. 后端接收并转发消息到对应机器人角色。
3. Master 负责识别、理解和下发动作。
4. Slave 负责执行、回传状态和视频流。
5. 视觉模块可独立推送识别结果到后端或主机。
